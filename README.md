
# BMI Calculator

A simple BMI Calculator built using Python.

## About the Project
This project calculates Body Mass Index (BMI) based on the user's weight and height. It displays the BMI value and the corresponding health category.

## Features
- Takes user's name, weight, and height as input
- Calculates BMI
- Displays BMI up to two decimal places
- Shows the BMI category
- Handles invalid numeric input
- Checks for positive weight and height

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python bmi_calculator.py
```

## BMI Categories
- Below 18.5: Underweight
- 18.5 to 24.9: Normal Weight
- 25 to 29.9: Overweight
- 30 and above: Obese
